## 一、研究结论摘要

### 核心发现

1. **"试卷手写擦除"是一个像素级语义分割 + 图像修复的复合任务**，不是简单的颜色过滤。单纯 HSV 阈值永远无法区分"黑笔手写答案"和"黑色印刷题干"。
2. **商业 API 已经成熟**：有道智云 0.0025元/次、TextIn 自动擦除，效果远超传统方案。适合先用 API 验证需求、再用本地模型替代。
3. **百度网盘 AI 大赛第一名方案（EraseNet）** 是可获取的最直接参考资料——端到端 img2img，mask 引导生成，PSNR 可达 38+。
4. **现阶段最务实路线**：方案A（传统 OpenCV 改良版，1-3天）+ 方案B（接入有道/TextIn API 做效果对比，1周）→ 方案C（本地部署 LaMa/SegFormer，长期）。

### 一句话建议

**不要继续在 HSV 颜色过滤上迭代。先跑通 API 调用验证效果天花板，再用 API 结果作为 ground truth 来训练/调优本地模型。**

## 二、试卷擦除功能的本质

### 2.1 这不是一个简单的任务

```
输入：手机拍摄的试卷照片（任意角度、光照、笔迹颜色、纸张材质）
处理：分离"印刷内容"和"手写内容" → 擦除手写 → 修复被手写覆盖的背景
输出：干净可打印的空白试卷

关键矛盾：
  - 黑笔手写 ≈ 黑色印刷（像素级不可区分）
  - 红笔批改 ≈ 红色印刷标记（也是像素级不可区分）
  - 手写可能覆盖在印刷字上方，擦除手写 = 损伤印刷字
```

### 2.2 正确的技术层次

```
Level 0: 颜色过滤（HSV 阈值）—— 只能处理蓝笔/红笔，永远处理不了黑笔
Level 1: 传统 CV + 连通域分析 —— 加几何特征过滤（面积/长宽比/笔画宽度）
Level 2: 语义分割模型 —— 区分每个像素是"印刷"还是"手写"
Level 3: 分割 + Inpainting —— 区分后，用图像修复算法恢复背景
Level 4: 端到端 img2img —— 输入原图，直接输出干净版（最强）
```

我们当前卡在 Level 0→1。

## 五、传统 OpenCV 改良方案（方案 A 详细版）

### 5.1 当前代码的问题

```python
# 问题代码（简化示意）
mask = cv2.inRange(hsv, lower_blue, upper_blue)  # 只能抓蓝色
result[mask > 0] = (255, 255, 255)                 # 直接涂白 → 背景变脏

# 三个核心问题：
# 1. 只处理了蓝/红色，黑笔完全忽略（也不敢处理——会误删印刷字）
# 2. 直接涂白导致背景不均匀（拍照的白不是 RGB 255/255/255）
# 3. 没有 mask 后处理（膨胀/腐蚀/连通域过滤）
```

### 5.2 改良方案

```python
# 改良步骤

# Step 1: 智能背景色采样（不是涂白 255/255/255）
def sample_background_color(img, mask):
    """从 mask 边缘外围采样真实背景色"""
    dilated = cv2.dilate(mask, kernel, iterations=3)
    border = dilated ^ mask  # 膨胀边缘 - 原 mask = 外围一圈
    if border.sum() > 0:
        bg_color = img[border > 0].mean(axis=0)
    else:
        bg_color = (255, 255, 255)
    return bg_color

# Step 2: 多级 mask 合并
color_mask = hsv_blue_red_mask(img)       # 蓝笔 + 红笔（高置信度）
gray_mask = hsv_dark_mask(img)             # 深色区域（低置信度，仅限已知答题区域）
combined = color_mask                     # 默认只用高置信度部分
# gray_mask 只在高置信度场景下作为辅助

# Step 3: mask 后处理（关键！）
kernel = cv2.getStructuringElement(cv2.MORPH_ELLIPSE, (3,3))
combined = cv2.morphologyEx(combined, cv2.MORPH_CLOSE, kernel)  # 闭合小孔
combined = cv2.dilate(combined, kernel, iterations=1)           # 覆盖笔迹边缘

# Step 4: 连通域过滤（去除误检）
num_labels, labels, stats, _ = cv2.connectedComponentsWithStats(combined, 8)
for i in range(1, num_labels):
    area = stats[i, cv2.CC_STAT_AREA]
    width = stats[i, cv2.CC_STAT_WIDTH]
    height = stats[i, cv2.CC_STAT_HEIGHT]
    aspect = max(width/height, height/width)
    # 面积太小 → 噪点，太大 → 印刷段落，长宽比太大 → 表格线
    if area < 20 or area > 5000 or aspect > 15:
        combined[labels == i] = 0

# Step 5: 局部背景色填充（不是全局涂白）
for contour in cv2.findContours(combined, ...):
    mask_single = np.zeros_like(combined)
    cv2.drawContours(mask_single, [contour], -1, 255, -1)
    bg = sample_background_color(img, mask_single)
    img[mask_single > 0] = bg
```

### 5.3 改良方案能做到什么

| 能处理 | 不能处理 |
|--------|---------|
| 蓝色/红色笔迹（高置信度） | 黑色手写与印刷同色区域 |
| 大部分批改痕迹 | 手写压在印刷字上的场景 |
| 纯白背景试卷 | 复杂背景（练习册横线、彩色背景） |

### 6.4 LaMa inpainting（最有希望的修复方案）

```
GitHub: https://github.com/advimman/lama
模型大小: ~200MB (PyTorch)
特点: 专为大面积 mask 修复设计，适合文档背景重建
Mac mini 48GB: ✅ 可 CPU 运行（单张 10-30s），GPU 加速更佳

使用方式（lama-cleaner）:
  pip install lama-cleaner
  lama-cleaner --model lama --device cpu --port 8080

  POST http://localhost:8080/inpaint
  body: { "image": base64, "mask": base64 }
```

**LaMa 对文档场景的价值**：文档背景通常有大面积重复纹理（纸张纹理、横线、格子），LaMa 的傅里叶卷积模块擅长捕捉这种周期性结构，比传统 cv2.inpaint 效果好得多。

## 七、OCR 与版面保护方案

### 7.1 为什么需要版面保护

擦除手写时最大的风险是误伤印刷内容。如果能**先识别印刷区域，标记为"保护区"**，擦除时让 mask 避开这些区域，就能大幅降低误伤。

### 7.2 可行的保护策略

```
策略 1: OCR 检测印刷文字区域 → 生成 protection_mask
策略 2: Layout Analysis 检测表格/图形/公式区域
策略 3: PaddleOCR 做中文印刷文字检测（轻量级，可本地运行）

最终 mask = handwriting_mask - protection_mask
```

### 7.3 PaddleOCR 本地集成

```python
# 只用于检测印刷文字位置，不做识别
from paddleocr import PaddleOCR
ocr = PaddleOCR(lang='ch', use_angle_cls=False)
result = ocr.ocr(img_path, cls=False)

# 将检测到的文字框标记为保护区
protection_mask = np.zeros(img.shape[:2], dtype=np.uint8)
for line in result[0]:
    box = line[0]  # 四点坐标
    cv2.fillPoly(protection_mask, [np.array(box, dtype=np.int32)], 255)
```
