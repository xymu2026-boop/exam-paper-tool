# 试卷宝项目总览

> 生成时间：2026-05-25
> 用途：让青山一眼看懂这个项目在做什么、怎么做、当前做到哪一步

---

## 1. 我们到底要做什么

处理孩子做过的试卷和练习册照片：

- **擦掉**手写答案、红笔批改、草稿痕迹
- **保留**题干文字、数学公式、几何图形、表格
- **输出**一张干净题目图，可以重新打印、重新练习

说人话：把写过的卷子变回空白卷子，让孩子可以再练一次。

---

## 2. 为什么不能一开始追求全自动

全自动看起来很美好，但真实试卷太复杂：

- **容易误删题干**：机器分不清"手写答案"和"印刷题目"，把题目擦了就完了
- **黑笔/铅笔和印刷字太像**：颜色、粗细都差不多，算法无法区分
- **公式和图形不能误伤**：分数线被擦掉 = 题目废了；三角形被擦断 = 整道题不能用
- **家庭学习材料不看"差不多"**：必须内容完全正确，不能"看起来对但实际错了"

> **结论**：先别想 AI 一键搞定，先用可靠的人机协作方案。

---

## 3. 当前最稳路线是什么

```
人判断哪里该擦 → 程序负责怎么擦
```

也就是**半自动路线**：

- 家长在图上框出"这里要擦掉"的区域
- 程序把该区域处理干净（涂白或智能修复）
- 家长确认结果

**为什么不丢人**：人是判断力的来源，代码是执行力的工具。这个分工让结果更可靠。

---

## 4. 四个阶段

| 阶段 | 目标 | 什么时候做 |
|------|------|-----------|
| **V0** | 验证能不能擦 | 🔴 当前 |
| V1 | 让青山能用起来（有简单界面） | V0 成功后 |
| V2 | 整理错题（识别题目，导出错题卷） | V1 稳定后 |
| V3 | 学习闭环（错因分析、复习计划） | 远期 |

---

## 5. 当前只做哪一步

**当前只做 V0。**

不做 V1（界面），不做 V2（错题），不做 V3（学习闭环）。

V0 只验证一个核心问题：用 5 张真实样本，看看能不能擦干净。

---

## 6. V0 成功标准

| 标准 | 要求 |
|------|------|
| 擦除效果 | 5 张样本中至少 3 张达到"可以打印重练" |
| 题干安全 | 0 张出现题干被误删 |
| 图形安全 | 公式、图形、表格不能被破坏 |
| 路线结论 | 明确知道涂白和 inpainting 各适合什么场景 |

---

## 7. 当前不做什么

- ❌ 不做 OCR（识别题目文字）
- ❌ 不做自动出卷
- ❌ 不做学习报告
- ❌ 不做云端上传
- ❌ 不做全自动模型训练
- ❌ 不做网页界面
- ❌ 不做 Hermes Skill 封装
- ❌ 不追求"看起来像成品"

**记住一句话**：V0 是把一个功能验证通，不是做一个产品。
