# 试卷宝 (Exam Paper Tool)

家庭试卷手写擦除工具 — 拍照→擦手写→输出干净试卷，全本地处理。

## 快速开始

```bash
pip install -r requirements.txt
```

> 项目处于早期阶段，详细计划见 [docs/plan.md](docs/plan.md)

## 项目结构

```
exam-paper-tool/
├── docs/            # 项目文档与规划
│   ├── plan.md      # 主计划
│   └── reference/   # 技术参考
├── experiments/     # 实验记录
│   └── v0/          # Phase 0 实验
├── src/             # 源代码
├── samples/         # 测试样本
├── tests/           # 测试
└── requirements.txt # 依赖清单
```
